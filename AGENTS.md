# Agent instructions

Read and follow [Project governance](docs/governance.md) before making repository
changes. It is the canonical guide for contributors and coding agents.

Use its **Where to look** table to select task-specific references. Follow
**Evidence and intent** when reconciling code, rules, and proposals, and
**Documentation and verification** for applicable checks and invariants.

Keep shared project policy in the governance document; keep this file a short
entry point rather than a duplicate ruleset.

Do not invoke subagents unless the user explicitly requests their use.

When writing or editing documentation, remove repetition, unnecessary defensive
caveats, and stale or irrelevant details. Preserve necessary constraints,
rationale, and historical context.
