## 目标与边界

以 `dc6ff5c`（PR #12，B+A2）为基线，通过所有最优和牌目标的缺牌并集，避免 `ukeire()` 逐种摸牌重复执行 `deficit()`，降低 `HeuristicPolicy::choose()` 的实际耗时。

**先证明并验证正确性，再评估性能，不预设一定更快。**完整 benchmark 达标才保留生产优化并提交到 PR，否则撤回生产优化、保留实验记录。本文是拟实现契约，不表示实现或验收已完成。

- 保留 `deficit()` 无 mask 快速路径、B 的七对纯距离公式和 A2 的精确剪枝，不无条件给所有 DP 状态增加 mask 成本。
- 不改精确性、规则、信息边界、动作合法性、得分结算或确定性；不引入近似。
- 不改策略的距离/ukeire 排序、听牌番数决胜、碰杠门控、收入及固定顺序回退。
- 生产改动限于私有分析及必要调用适配；允许独立测试和可重建实验工具，不顺带重构、不建设通用性能框架、不引入全局预计算。

遵循[项目治理](../../../docs/governance.md)和[固定规则](../../../docs/baseline-rules.md)，规格原地修订。实现入口为 [`analysis.rs`](../../../src/policy/analysis.rs)、[`heuristic.rs`](../../../src/policy/heuristic.rs)；复用现有[分析测试](../../../src/policy/analysis/)及 [`heuristic_bench`](../../../examples/heuristic_bench.rs)。[历史验证](../../../docs/validation.md)不是本轮性能保证。

## 精确行为契约

上下文 `C` 固定自家副露、缺门及容量，合法目标集合为 `T_C`：

```text
c_H(T) = sum_t max(0, T[t] - H[t])
D_C(H) = min_{T in T_C} c_H(T)
Optimal_C(H) = { T in T_C | c_H(T) = D_C(H) }
```

目标暗牌数为 `14 - 3m`，不含缺门，与自家副露合计每种不超过四张；多余手牌免费舍弃。比较 `H` 与 `H+t` 时目标集合不变。他家公开牌只影响可得张数，不改变目标容量或距离。

新增仅供 ukeire 使用的精确分析，返回 `(deficit, improving_mask)`：

- `deficit == D_C(H)`，与原路径完全相同。
- mask 为 `u32` 低 27 位，按 `Tile` 索引编码，高位为零。
- 第 `t` 位成立，当且仅当存在 `T in Optimal_C(H)` 满足 `T[t] > H[t]`；合并所有并列最优目标，同一牌种只计一次。
- mask 独立于 `public`/`unseen`；公开耗尽不能删除结构上应成立的位。

生产 ukeire 的 `H` 是弃牌后或杠声明后补张前的等效手牌，大小为 `13 - 3m`；若保留距离参数，必须是同一上下文下的 `D_C(H)`。输出为：

```text
improves(t) iff D_C(H+t) < D_C(H)
unseen[t] = max(0, 4 - H[t] - public[t])
ukeire = sum of unseen[t] over legal, non-missing, improving kinds
```

必须沿用自家碰后目标容量 1、杠后容量 0、四张物理上限及缺门限制。`public` 沿用所有副露和未被碰杠取得的舍牌计数：自家副露、被鸣牌取得的舍牌、多家胡引用的舍牌均不重复计数；候选弃牌及假设碰杠后的调整不变。公开耗尽不改变距离、听牌和番数决胜语义。

“One-Pass”指在最优距离分析中传播缺牌并集，不要求字面上只有一个循环，但不得仍逐种摸牌执行完整距离 DP。仅删除和牌检查或增加缓存共享不满足目标。不扩大非法输入支持范围，也不缩小原有支持域或破坏防御性处理。

## 证明与实现约束

完整证明作为交付，至少落实以下内容，并对应实际实现：

1. 对固定目标有 `c_{H+t}(T) = c_H(T) - indicator(T[t] > H[t])`。据此证明在目标集合固定、距离有限且摸牌合法时：
   `D_C(H+t) < D_C(H) iff exists T in Optimal_C(H): T[t] > H[t]`。
2. 新分析的 `suit_table` 状态保存最低 cost 及达到该 cost 的全部部分目标缺牌并集。当前牌种目标需求超过持有量时加入其位；更低 cost 替换 cost/mask，同 cost 按位 OR，更高 cost 不贡献。证明同状态后续可扩展条件相同，且不可达状态不会通过 `INF` 运算产生伪 mask。
3. 跨花色合并时成本相加、mask 合并，再按相同规则归并；正确映射局部/全局位。保留并验证完整 `[sets][pair_used]` 表，不仅验证最终距离。
4. 七对仅无副露时合法：14 张、无缺门、每种目标计数 `0/2/4`、共七个对子单位，四张顶两对。须求其完整最优目标缺牌并集，不能未经证明使用奇数牌集合；覆盖零持有量、三张、四张和缺门未清。标准型与七对取较低距离的 mask，并列时 OR。
5. 若删除原版直接和牌短路，证明并测试合法尺寸/副露前提下 `can_hu(H+t) iff D_C(H+t) == 0`，不修改其他和牌或番数路径。

缓存键语义及 evaluator 生命周期不变：花色键为 `(花色, 九档计数)`，完整手牌键为 27 种计数，副露/缺门/容量由固定上下文隔离。新增 mask 缓存须与纯距离缓存分离；纯距离命中不代表 mask 已计算。不扩展跨决策缓存，也不要求保留旧逐张算法产生的假设摸牌条目。

冷暖缓存、填充顺序、重复查询、fresh/reused evaluator 不影响数值或动作；策略无逻辑历史，`Game::clone` 后换全新策略仍精确续局。

## 正确性验收

必须同时使用两类独立参考，仅在测试或隔离实验中保留：

- **兼容参考：**冻结 `dc6ff5c` 原版逐张 ukeire 及所需距离实现，不调用被测 mask 路径、不共享被测缓存。
- **定义参考：**独立具体目标枚举，求距离和全部最优目标的缺牌并集，不复用被测转移。

固定 seed 的随机合法状态与定向边界用例须覆盖：副露 `0..4`、三种缺门及未清/已清；碰/明杠/暗杠/加杠及假设评估位置；公开可得/部分耗尽/完全耗尽；自家容量及四张上限；标准型内部、七对内部、两路线之间的并列最优；直接和牌、普通改善、不改善、零进张；全部缓存条件。

比较完整 deficit、每种牌的改善判定和 `unseen` 贡献及 ukeire 总和；结构 mask 不能仅检查 `unseen > 0` 的牌。花色测试覆盖完整表、目标面子数及容量模式，保留既有 B/A2 独立测试。随机输入须物理所有权一致，记录生成方法、seed、样本量及可复现反例。

另行采集基线/候选逐局完整轨迹，精确比较动作及顺序、距离、ukeire、逐局得分、胜者、决策数、终局原因及 clone/新策略续局。`run_batch` 的聚合结果不能代替逐动作验证；trace 采集不进入正式计时。

须通过 `cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --all-targets` 和 `cargo test --release --all-targets`。规则冲突单独报告，不借优化静默修正；正确性失败不得进入性能验收，也不得放宽测试。

## 性能实验与去留

### 测量与配置

分别测量纯 `deficit()`、新 mask 分析、ukeire 和完整 `heuristic_bench`，注明输入、重复次数及冷暖缓存条件。报告纯距离退化与否、新分析成本和局部/整体收益，不以理论倍数、历史占比或微基准代替端到端结论。

实际记录 `deficit`/mask 分析/ukeire 调用次数，各类缓存查询/命中/未命中、花色 DP 构建次数、原版直接和牌短路次数。不得从牌种检查次数推算 DP 次数；有扰动的插桩与正式计时隔离，保留可重建材料和构建对应关系。

| 项目 | 要求 |
| --- | --- |
| 构建 | 相同工具链、target、release profile、编译参数；先构建并保存二进制，直接运行 |
| 工作负载 | `heuristic-benchmark-v1`；默认 `games=2000`、`warmup=20`，遵循既有阶段与计时语义 |
| 起始 seed | `7`、`10007` |
| 重复 | 每组五对，共 20 次正式进程运行；每对参数相同 |
| 顺序 | 每组依次为 B→C、C→B、B→C、C→B、B→C（B 基线，C 候选） |
| 隔离 | 全部串行；构建、测试、采样及 trace 不与计时运行重叠 |

正确性通过后，先做基线/基线配对试跑检查能否分辨 2%。差异反复接近或超过 2% 时，先排除环境干扰，必要时统一增加游戏数，再记录并锁定正式配置、次数和顺序；seed 和收益门槛不变，不利用试跑选择有利候选的参数。正式比较开始后不按候选结果修改方案。

### 通过与停止条件

对每项耗时定义配对降幅 `r_i = 1 - candidate_time_i / baseline_time_i`，使用五个降幅的中位数，不用最快样本或两边独立中位数替代。

**两组 seed 各自必须同时满足：**

| 指标 | 最低收益 | 稳定性 |
| --- | --- | --- |
| 批次 `total_time` | 中位配对降幅 ≥2% | 至少 4/5 对严格改善 |
| 累计 `policy_time`（`choose()`） | 中位配对降幅 ≥2% | 至少 4/5 对严格改善 |

两项指标的改善对可不同，所有非计时结果须完全一致。2% 是工程门槛，上述条件不是统计显著性证明；“候选最大耗时低于基线最小耗时”仅作辅助证据。

按五对完成，不追加到通过为止。只有明确外部干扰或执行失败才使完整配对失效并补跑，须保留证据及全部原始输出，不能因耗时不利剔除样本。

- 正确性及两组完整 benchmark 均通过：保留优化并提交到 PR。
- 变慢、收益不足或不稳定：撤回生产优化，保留实验记录及原因分析。
- 正确性失败或环境不能支持有效测量：记录阻塞，不宣称通过，不以证据不足保留生产优化作为完成结果。

未通过后可提出有明确原因的新实验，但须运行前修订规格并保留失败证据，不能追认本轮通过。
