# Bounded exact Needed-mask DP：历史验收摘要（2026-11-06）

**结论：保留最小 Needed cutoff，Change 已归档。** 原实验合同见 [spec.md](spec.md)。

生产改动集中在 `src/policy/analysis.rs`：`ukeire` 把已有精确 `d` 传入私有的
`deficit_with_mask_bounded`，花色内核在写后继前拒绝严格 `cost>d`，保留 `cost=d`，
状态、枚举顺序、同价 OR 与 mask 合并规则不变；复用更宽／完整表时过滤超界项，花色表
与标准型路线的超界值统一归一为 `(INF,0)`，七对按原规则合并。完整表优先服务有界
查询；有界表按 key 记录构建 cutoff，只在覆盖请求时复用且不写完整缓存；精确整手结果
可共享原 `hand_mask_cache`。普通距离与 Surplus 路径不查也不分配有界缓存，无界内核
以编译期常量消除 cutoff 检查。未实施更强下界、提前 break、Dual-mask 或其他捆绑优化，
规则、策略排序、碰杠门控、精度、公开 API、信息边界与 checkpoint 语义均未改变。

剪枝依据是各转移新增代价非负：总成本不超过 `d` 的目标，其所有前缀与各花色成本
均不超过 `d`；相同 rank／状态的未来延伸又不依赖前缀身份，所以严格超界路径不可能
贡献最优 mask，等号路径却可能零代价完成。这也保证有界整手结果仍是完整 `(D,M)`。

按用户提交前的清理要求，一次性研究插桩、源码 patch、固定 collector、原始计数、
逐对计时、轨迹、日志与二进制镜像均已删除，取代原合同的材料保留要求。**下述数字
仅为历史摘要，不能从仓库原始样本重新核验或重算；复测须重新采集全部观测。**
被测实现即以本 PR 提交的源码为准，不依赖某个孤立历史 commit；下文候选身份只说明
当时的测量来源。

## 工作量与验收

阶段一用真实请求流做研究侧影子执行（每 seed 2000 局、warmup 20，预热不计入，串行）。
两个 seed 的合法转移枚举数 `N0→Nd` 为 290,199,772→140,021,608 与
299,247,172→145,352,795，即 `ρ` **51.75%／51.43%**。当前每 evaluator 的 `d` 固定，
按候选 key／cutoff 覆盖规则可推得请求／命中／构建数不变，因此净 DP 转移减少与核内
比例相同。这是该请求流的结构性推论，不是新增候选插桩数据；转移减少本身不是速度结论。

正式验收同为 `heuristic-benchmark-v1`，每 seed 2000 局、warmup 20；先 3 对 B/B 校准，
再 5 对 B/C，顺序 `BC、CB、BC、CB、BC`。全部串行、直接调用保存的无插桩镜像，无剔除、
替换、重试或追加样本；降幅为每对 `1-C/B` 的中位数。

| 指标 | seed 7 | seed 10007 |
| --- | ---: | ---: |
| 转移枚举减少 `ρ` | 51.7499% | 51.4272% |
| 配对 total 中位降幅 | **23.6257%** | **23.9417%** |
| 配对 policy 中位降幅 | 24.2073% | 24.4610% |
| B/B 三对最大绝对波动 | 2.6550% | 1.8141% |
| 端到端严格改善对 | 5/5 | 5/5 |

两组均满足原门槛（≥4/5 改善，且配对中位降幅严格超过 B/B 最大绝对波动），未设 2%
下限；策略时间只报告、不设门槛；未用两侧独立中位数相除代替配对统计。策略／规则
时间不代表规则实现本身加速或策略质量提高。

## 限制

- B/B 只刻画校准期：seed 7 的 B 从校准中位 3.867621 s 上漂至比较中位 4.053538 s
  （+4.81%），seed 10007 从 3.951809 s 至 4.114461 s（+4.12%）；比较期 seed 10007
  第二对 B/C 都较慢。当时全部纳入判定，未作漂移校正、剔除或追加，也没有 CPU 绑核／
  频率控制或后台活动采样，不能确定漂移原因。
- 本机两个 seed 的结果不能推出跨机器保证或统计显著性；未追加长批次确认性实验，
  也未研究 `g+L(X)>d` 或其他更强下界。
- 原始样本、逐对计时、轨迹与计数 JSON 已删除，无法重算本文数字或复核分桶分布；
  实现和永久回归测试仍在源码中，可重新验证正确性。

## 复测

在两个独立 checkout 分别构建并保存二进制，串行交错运行：

```sh
cargo build --release --locked --example heuristic_bench
<saved-binary> --games 2000 --seed 7 --warmup 20
<saved-binary> --games 2000 --seed 10007 --warmup 20
```

也不保证重现原数值。
