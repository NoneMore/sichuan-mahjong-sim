## 工作量（非计时验收）

独立研究插桩使用相同短批请求流，每 seed 的 B/C 各重复两次，预热与测量
分别计数；两次完全确定，B/C 请求及缓存分类计数相同，测量决策数与正式
产物一致。状态计于全部状态 cutoff 后，合法转移计于结构/容量检查后、
后继 cutoff 前；缓存命中不虚构 DP 工作，保持原有阶段语义。

| seed / phase | 状态 B → C | 合法转移 B → C |
|---|---|---|
| 7 / warmup | 348130 → 204801 | 1409660 → 1038980 |
| 7 / measured | 34308478 → 20017802 | 140021608 → 102254976 |
| 10007 / warmup | 331980 → 194526 | 1379446 → 1007896 |
| 10007 / measured | 35673624 → 20755580 | 145352795 → 106051189 |

测量阶段状态减少约 41.7%–41.8%、转移减少约 27.0%，仅说明剪枝生效，
**不能替代端到端性能通过**。
