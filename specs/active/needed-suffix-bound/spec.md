# Needed-mask DP：顺子尾部必需牌下界（进行中的实验）

## 状态与目标

以 PR #15 的 `spec/bounded-exact-needed-dp@e7bd04ba` 为基线，独立研究在
`g > d` 精确 cutoff 之后，能否进一步减少 Needed-mask 花色 DP 的搜索工作。
候选仅修改 `suit_table_masked_kernel::<false, true>` 的有界路径；不得改变
规则、牌效、策略排序、公开 API、缓存 key/生命周期、七对处理或其他路径。
不默认保留候选：需要正确性和真实 Rust A/B 两关都过。

## 数学下界

当前处理 rank `r` 时，状态 `(a,b,k,p)` 中：
- `a` 为从 `r-2` 开始的顺子在当前 rank 必须占用的张数；
- `b` 为从 `r-1` 开始的顺子在当前 rank 和 `r+1` 必须占用的张数。

未来任何目标在 rank `r` 至少放 `a+b` 张，在 rank `r+1`
至少放 `b` 张。因此下面是尚未支付补牌成本的下界：

```text
L_r = max(0, a+b - hand[r]) + max(0, b - hand[r+1])
```

当 `r=8` 时第二项视为 0（合法顺子不会跨出 9）。这两项作用在不同
牌种上，不能互相抵消。若当前前缀累计成本为 `g`，调用方提供的
`d=D_C(H)` 为同上下文的**精确最优全手距离**，则

```text
g + L_r > d  => 此状态无法贡献全局最优解，可直接不扩展
```

严格 `>` 必须保留 `==` 的全部路径；`L_r` 只依赖相同 rank/state
与手牌，故不会遗漏来自等价前缀的 mask OR。
状态转移、其它剪枝及归一化逻辑不变。用 const-generic
`BOUNDED` 禁止无界 Needed/Surplus 额外付费。

## 第一轮独立工作量探针（不是生产 benchmark）

在不能运行 Rust/Cargo 的隔离环境中，以 C++ 对照探针复现原 250 槽位 DP
的花色转移、Need-mask 同价 OR、已有 `g>d` 及本次状态级下界。
抽样种子为 `0x5eed1234`，两组各 50,000 副物理上限为四张的 13 张手牌：

- 随机 108 张牌堆无放回取 13 张，缺门随机：原/新合法转移尝试
  92,564,608 / 70,109,097，减少 **24.26%**。
- 两种非缺门花色内，以固定合法 14 张标准目标为基础，随机删 1–5 张，
  补入随机非缺门牌使剩余手牌数为 13：原/新尝试
  59,735,500 / 43,526,705，减少 **27.13%**。
- 以上共 100,000 副模拟手牌、300,000 个花色配置；
  参考 `g>d` 和额外下界版本的 5×2 `(cost,mask)` 表**无差异**。
  独立仿真还测试了状态级与后继级两种下界配置，结果一致。

这些数字非真实对局请求流、未考虑 per-evaluator 缓存、碰/杠容量的分布，
不能据此推断 Rust 速度或最终应保留候选。

## 已实现的最小候选

- 在既有 `reserved > rank_capacity` 检查后、状态转移枚举之前，
  对 **BOUNDED** 执行一次 `g + L_r > cutoff` 判断。
- 保留原有后继 `cost > cutoff` 检查与所有同价 mask OR。
- 新增针对稀疏手牌、未来 rank 缺牌和非均匀容量的 concrete-target oracle
  测试；既有所有有界/完整表、全手、缓存冷热、动作轨迹测试继续适用。
- 本地隔离环境**没有 Rust/Cargo**，所以尚未执行任何 Rust
  `fmt`、`clippy`、测试或端到端基准。候选属于待验证研究，不宣称验收通过。

## 下一步独立验收

在具备 Rust 的机器，基于 PR #15 当前有界版与本候选分别构建默认 Release，
先通过：

```sh
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
cargo test --release --all-targets
```

再用同一组真实自对弈 seed 7/10007、每次 2000 局和 warmup 20，
分别计数合法转移/状态扩展（研究插桩不能参与正式计时）和
无插桩 Release 的端到端耗时。沿用 PR #15 的预注册 3 对 B/B 校准、
5 对交错 B/C、每 seed 至少 4/5 次改善且中位配对改善大于 B/B
最大绝对波动的标准。由于前一轮本机存在约 4%–5% 漂移，
增加预先确定的长批次作为交叉检查，不因结果不好更换样本。
需保存原始逐对数据，性能验收后才决定保留还是回滚。
