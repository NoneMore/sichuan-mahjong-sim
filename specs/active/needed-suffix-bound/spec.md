# Needed-mask DP：顺子尾部必需牌下界

## 目标与范围

在已有 `g > d` cutoff 上增加顺子尾部下界，减少有界 Needed-mask DP
搜索。**正确性等价与真实 Rust 端到端性能均通过才可保留候选。**

- **B**：PR #15 已合入的 `9390264`（原引用 `e7bd04ba`），无本次下界。
- **C**：B 加本次下界；固定双方源码与产物，生产差异仅限本候选。

仅在 `suit_table_masked_kernel::<false, true>` 的既有容量检查后、转移
枚举前增加状态级剪枝。状态转移、后继 cutoff、同价 mask OR、归一化、
七对、规则、牌效、策略排序、公开 API 及缓存语义与生命周期均不变。
用 const-generic `BOUNDED` 隔离，不能让无界 Needed/Surplus 路径额外付费。

## 剪枝契约

rank 使用 `0..=8`。处理 rank `r` 前，状态 `(a,b,k,p)` 中：

- `a`：从 `r-2` 起的顺子在当前 rank 必须占用的张数；
- `b`：从 `r-1` 起的顺子在当前及下一 rank 必须占用的张数；
- `k,p`：沿用既有面子数与将牌状态。

`g` 仅累计 ranks `< r` 的最小补牌成本。全手调用的 `d` 必须是同一
手牌、副露、缺门和容量上下文的**精确最优全手距离**，由既有调用方精确
计算并以 release 差分测试验证；不新增运行时校验，不以 debug 断言代替验证。

```text
L_r = max(0, a+b - hand[r]) + max(0, b - hand[r+1])
g + L_r > d  => 跳过该状态的扩展
```

当前及下一 rank 的目标占用分别至少为 `a+b`、`b`，两种牌的缺口不能
互抵；其他成本非负，故此下界可安全剪枝。`L_r` 不依赖前缀路径，保留状态
时仍完整合并同价 mask。必须用严格 `>`，保留 `== d` 的全部路径。
减法取非负差、求和不溢出；`r=8` 时第二项为 0，不读取 `hand[9]`。
既有合法性检查继续有效，本次不增加其他容量剪枝。

有界花色 `5×2 (cost,mask)` 表必须保持 B 的合同：完整表中成本不大于
cutoff 的项精确保留，其余为 `(INF,0)`。可用独立 concrete-target oracle
的完整表截断验证，不必冻结 B 内核；花色单测可独立选 cutoff。
全手在精确 `d` 下，距离、全部最优 Needed mask、牌效及动作必须与 B 等价。

## Rust 性能验收

沿用[前轮协议](../../archive/bounded-exact-needed-dp/spec.md#6-阶段四性能验收)，
在相同工具链、默认 Release 和环境下分别构建并保存 B/C 无研究插桩产物：

```sh
cargo build --release --locked --example heuristic_bench
<binary> --games 2000 --seed 7 --warmup 20
<binary> --games 2000 --seed 10007 --warmup 20
```

四座 Heuristic 自对弈；warmup 与测量各用新 Runner/策略，阶段内跨局复用。
以 `BatchReport.total_time`（报告字段 `total_time_seconds`，含建局，不含
进程启动和 warmup）验收，另报 policy/rules 时间与吞吐量，不设其门槛。

- 先 3 轮 B/B，再 5 轮 B/C；每轮先 seed 7 后 10007，各运行一对。
  B/C 方向依次 `BC、CB、BC、CB、BC`，共 32 个测量批次。
- 每 seed 令配对改善 `r_j = 1-C_j/B_j`，本轮校准噪声
  `n = max_{k=1..3}|1-B_{k,2}/B_{k,1}|`，均使用 `total_time`。
- 两个 seed 分别满足：至少 4/5 对 `r_j>0`，且 `median(r_1..r_5)>n`。
  不设 2% 下限，不用独立中位数相除或合并 seed 代替配对判定。

全部串行，不与构建、测试、trace 或计数重叠；预先固定异常处理，不按结果
剔除、替换或追加样本。保存构建身份、环境、运行顺序、原始输出和非计时
统计；执行失败或非计时结果不一致须先排查，不能作正常性能样本。

另用研究插桩在同一真实请求流统计状态扩展与合法转移尝试，B/C 口径一致，
不设下降比例门槛，且不参与正式计时。工作量下降不能代替端到端通过。
正确性失败则修正或回滚；性能不通过不默认保留，噪声过大则记录未决。

## 历史证据（非验收结果）

候选及 oracle 回归测试已存在，但不等于验收通过。早期无 Rust/Cargo 的
隔离环境用 C++ 探针抽样：seed `0x5eed1234`，三组各 50,000 副，分别为
随机 13 张、固定标准目标扰动后补至 13 张（每牌种不超过四张）、0–4 副露
的物理一致手牌。合法转移减少分别为 **24.26%、27.13%、20.60%**；共
450,000 个花色配置的 B/C 表无差异，状态级与后继级下界探针结果一致。
这些不是 Rust 测试或真实缓存请求流，不能推断 Rust 加速比或保留结论。
