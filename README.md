# Sichuan Mahjong Simulator

A Rust research simulator for four-player Sichuan mahjong (血战到底),
with seeded self-play, policy comparisons and behavior-cloning experiments.

## Rules

The fixed 108-tile deck has three numbered suits, with four copies of each
rank (1–9). Players exchange three tiles, declare a missing suit, and
continue after Hu until three seats win or the wall ends.
Hu has priority over kong and peng; multiple players may Hu one discard.
Scoring uses additive fan capped at 5 and zero-sum settlement.

[Full rule contract](docs/baseline-rules.md)

## Use

The root CLI offers `first` and `random` policies. Heuristic and
missing-only policies are available through the Rust library and
comparison examples. The separate neural pipeline collects teacher
episodes, prepares NumPy datasets, trains checkpoints and evaluates frozen
policies online. Model weights and prepared datasets are generated by
that workflow.

```sh
cargo test --workspace --all-targets
cargo run --release -- --games 1000 --seed 7 --policy first
```

Requires Rust 1.75+.

## Architecture and guides

`Game` owns state and rules; `Policy` chooses from player-visible
`Decision` values; `Runner` drives games and records reports.
